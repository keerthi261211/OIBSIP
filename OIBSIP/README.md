Data Cleaning Project – Cafe Sales Dataset

Internship

Oasis Infobyte – Data Analytics Internship

Task

Level 1 – Task 3: Data Cleaning

Project Overview

This project focuses on cleaning a cafe sales dataset by identifying missing values, invalid entries, duplicate records, and potential outliers.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Work Performed

1. Loaded and explored the dataset.
2. Checked missing values and data types.
3. Identified invalid entries such as "ERROR" and "UNKNOWN".
4. Handled missing values using suitable methods.
5. Checked and removed duplicate records.
6. Identified potential numerical outliers using the IQR method.
7. Corrected column data types.
8. Saved the cleaned dataset as a CSV file.

Files

- "Keerthana_Task3.ipynb" – Notebook containing the analysis and cleaning steps.
- "Keerthana_Task3_Cleaned.csv" – Cleaned dataset.

Conclusion

The project demonstrates basic data cleaning techniques using Python and Pandas to improve dataset quality and prepare data for further analysis.
