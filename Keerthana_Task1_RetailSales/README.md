Retail Sales Exploratory Data Analysis (EDA)

Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to understand sales performance, customer behaviour, and product category trends.

Dataset

The dataset contains 100 retail transactions with details such as:

- Transaction ID
- Date
- Customer ID
- Gender
- Product Category
- Quantity
- Price per Unit
- Total Amount
- Payment Method

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Analysis Performed

1. Dataset loading and inspection
2. Missing value and duplicate checking
3. Total sales analysis
4. Product category analysis
5. Monthly sales trend
6. Gender-wise sales analysis
7. Payment method analysis
8. Top 5 customer analysis
9. Quantity sold analysis
10. Average, highest, and lowest sales
11. Correlation analysis

Conclusion

The project helps understand retail sales patterns through data analysis and visualizations. It provides insights into product performance, customer purchasing behaviour, and payment preferences.
