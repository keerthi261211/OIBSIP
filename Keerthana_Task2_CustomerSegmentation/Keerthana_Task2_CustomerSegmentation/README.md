Customer Segmentation using K-Means Clustering

Project Overview

This project uses customer data to identify different customer groups based on annual income and spending score.

Dataset

The dataset contains 200 customer records with the following details:

- Customer ID
- Gender
- Age
- Annual Income
- Spending Score

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Project Steps

1. Load and inspect the dataset.
2. Check missing values and duplicates.
3. Analyze age, income, and spending score.
4. Visualize customer data.
5. Scale the data using StandardScaler.
6. Use the Elbow Method to select the number of clusters.
7. Apply K-Means clustering.
8. Visualize and analyze customer segments.
9. Save the segmented dataset.

Conclusion

K-Means clustering was used to group customers based on annual income and spending score. The results help understand customer behaviour and support targeted marketing strategies.
